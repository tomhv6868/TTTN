Gate kỹ thuật đã **đạt** và được người dùng chọn **Chấp nhận** ngày 2026-07-14. Receipt `run_log/t0.5/acceptance.json` đạt 7/7 check trên Ubuntu 24.04 x86_64. C++20 core, runtime linkage smoke và toàn bộ Python unittest đều hoàn thành với mã trả về 0.

## CI

Workflow `.github/workflows/ci.yml` dùng `ubuntu-24.04` và Python 3.12, sau đó:

1. configure Release với `NIDS_BUILD_TOOLCHAIN_SMOKE=OFF`;
2. build `nids_core` và C++ test;
3. chạy CTest;
4. chạy toàn bộ Python unittest.

CI cơ bản không tải hoặc biên dịch DPDK/ONNX Runtime. Runtime linkage smoke chỉ thuộc gate Ubuntu lab, nơi toolchain khóa đã được cài đặt và xác minh từ T0.2.

## Lệnh tái lập

Chạy bằng user thường trên Ubuntu:

```bash
cd /mnt/hgfs/TTTN
source "$HOME/.local/nids-toolchain/env.sh"
python3 scripts/verify_project.py run
```

Verifier từ chối ghi đè receipt đã tồn tại. Muốn chạy một acceptance mới phải lưu receipt hiện tại sang thư mục lịch sử hoặc dùng output mới nằm dưới `run_log/t0.5/`.

## Giới hạn

- Workflow GitHub Actions mới được kiểm tra bằng unit/static contract; chưa có run trên GitHub vì repository chưa có remote.
- `nids_core` hiện chỉ cung cấp version API nhằm chứng minh cấu trúc và toolchain; chưa phải NIDS runtime.
- Build sạch xác minh dependency linkage, không cấu hình hugepages, VFIO hoặc NIC DPDK.
- Chưa tạo commit theo phạm vi đã duyệt; việc commit/push cần quyết định riêng của người dùng.
