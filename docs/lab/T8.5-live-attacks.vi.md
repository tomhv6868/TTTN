# T8.5 - Demo live attack tu Kali

Runbook nay danh cho buoi demo ma thay yeu cau tan cong truc tiep tu Kali vao
Windows victim. Workflow nay tach rieng voi golden PCAP demo va full replay
theo ngay.

## Trang thai

- Ubuntu sensor chay DPDK live tren `ens160`.
- Kali tan cong tu `eth1`. Rehearsal that tren may hien tai di ra bang
  `192.168.252.129/24`; neu ban doi lai Kali thanh `192.168.252.10/24` thi
  truyen `--source-cidr 192.168.252.10/24`.
- Windows victim la `192.168.252.20`.
- Moi attack dung mot sensor process rieng de flow state bat dau rong.
- Evidence ghi vao `run_log/t8.5/live-attacks/<run-id>/<attack>/`.
- Kali receipt chi chung minh tool da chay va ghi log. Chi `nids_alert` trong
  `detection.jsonl` moi duoc dung de claim model classification.

Hien tai wrapper da static-verified. Chua co rehearsal receipt live that cho
`hping3` hoac `ftp-patator` trong `run_log/t8.5/live-attacks/`.

Luu y sau rehearsal dau tien: sensor da bat alert, nhung alert di tu source
`192.168.252.129`, khong phai `.10`. Wrapper moi fail-fast neu route den
Windows khong dung source CIDR da khai bao.

## 1. Attack hping3

Terminal Ubuntu sensor:

```bash
cd /mnt/hgfs/TTTN
bash scripts/ubuntu_t85_live_attacks.sh \
  --run-id teacher-demo-20260726a \
  --attack-id hping3 \
  --bundle /home/tom/.cache/nids-partial-flow/t5.2/bundles/F9
```

Cho den khi thay event:

```text

```

```bash
cd /mnt/hgfs/TTTN

  --run-id teacher-demo-20260726a \
```

## 2. Attack FTP Patator

Dung run-id moi hoac cung run-id nhung attack-id khac. Sensor phai la process
moi.

Terminal Ubuntu sensor:

```bash
cd /mnt/hgfs/TTTN
bash scripts/ubuntu_t85_live_attacks.sh \
  --run-id teacher-demo-20260726a \
  --attack-id ftp-patator \
```

## 3. Kiem chung nhanh sau moi attack

Tren Ubuntu:

```bash
cd /mnt/hgfs/TTTN
grep -F 'nids_dpdk_live_ready' run_log/t8.5/live-attacks/teacher-demo-20260726a/hping3/detection.jsonl
grep -F 'nids_dpdk_live_summary' run_log/t8.5/live-attacks/teacher-demo-20260726a/hping3/detection.jsonl
grep -F '"status": "passed"' run_log/t8.5/live-attacks/teacher-demo-20260726a/hping3/ubuntu-runtime/rollback.json
```

Doi `hping3` thanh `ftp-patator` de kiem attack thu hai.

Neu `detection.jsonl` co `nids_alert`, co the trinh model decision/candidate trong
alert do. Neu khong co alert, khong claim model da nhan dung attack do; chi trinh
Kali receipt va sensor readiness/summary, roi dung golden PCAP live demo da pass
lam bang chung model alert on-NIC.

Trong rehearsal `teacher-demo-20260726a`, hping3 sinh nhieu alert
`unknown_candidate` voi top candidate `DDoS`; FTP Patator sinh alert
`unknown_candidate` nhung top candidate khong phai `FTP-Patator`. Khong noi voi
thay la model da phan loai dung family cho hai live tool nay; noi la sensor bat
duoc traffic attack live va danh dau bat thuong.

## Gioi han khi bao cao

- Khong dung `run_log/t8.5/detection.jsonl` cu lam bang chung cho hai attack nay.
- Khong dung `run_log/t8.5/segments/<day>/` cho live hping3/patator.
- Khong them `--flood` cho hping3; wrapper khoa toi da 100 pps.
- Khong cai tool trong wrapper. Neu Kali thieu `hping3` hoac `patator`, wrapper
  fail-fast.
- `unknown_candidate` khong dong nghia zero-day that.
- VMware Workstation la lab demo, khong phai bang chung hieu nang production.
